# 浮生诗集  设计定稿

本目录是《浮生诗集》Android App 的最终设计定稿。

- 完整说明：`设计定稿.md`
- 可打印版本：`设计定稿.pdf`
- 网页版本：`设计定稿.html`
- 视觉总览：`视觉稿总览_定稿.png`
- 单页视觉稿：`视觉稿/01-浮生馆.png` ~ `视觉稿/06-我.png`

## 定稿核心

- 底部五键固定，名称、顺序、形态不变。
- 视觉概念：手卷 / 笺纸 / 竖排诗 / 朱砂印 / 深墨木轴底栏。
- 浮生馆图片按原图方向处理：横图按原比例（16:9  316178dp），竖图按原比例（4:5  190238dp），方图 240240dp。
- 图片下缘不加波浪线、裱纸边、下划线、投影或圆角。
- 所有操作遵循 Android 常规习惯，全本地，无账号、无社交、无云同步。
